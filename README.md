# GMASTER ARCHIVE

건담 우주세기(Universal Century)의 역사·전쟁·사건·모빌슈트·세력 정보를 연결해 정리하는 비공식 팬 아카이브입니다.

## 파일 구성
- `index.html`: 웹사이트 구조
- `styles.css`: 반응형 UI 및 디자인
- `data.js`: 우주세기 사건·기체·세력 데이터
- `app.js`: 연표, 검색, 필터, 상세 정보 화면

## 주요 기능
- U.C. 0079~0153 주요 사건 연표
- 전쟁 및 사건 상세 기록
- 모빌슈트 형식번호·개발 주체·소속·무장·기술 데이터
- 사건과 참전 기체, 세력 정보 연결
- 키워드 검색 및 시대별 필터
- 모바일 화면 대응

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` / `/(root)` 선택.

## 데이터 원칙
작품 본편, 극장판, OVA, 소설, 만화, 게임 등 매체별 설정이 일치하지 않을 수 있습니다. 연표의 날짜와 기체 설정은 공식 자료를 기준으로 재검증하고, 정사/외전/매체별 차이를 구분해 확장합니다. 현재 데이터는 초기 큐레이션이며 완전한 공식 연표를 의미하지 않습니다.
