# GMASTER ARCHIVE

건담 우주세기(Universal Century)의 역사·전쟁·사건·모빌슈트·세력 정보를 연결해 정리하는 비공식 팬 아카이브입니다.

## 파일 구성
- `index.html`: 웹사이트 구조
- `styles.css`: 반응형 UI 및 디자인
- `data.js`: 우주세기 사건·기체·세력 데이터
- `app.js`: 연표, 검색, 필터, 상세 정보 화면

## 주요 기능
- U.C. 0079~0153 주요 사건 연표
- 전쟁 및 사건 상세 기록
- 모빌슈트 형식번호·개발 주체·소속·무장·기술 데이터
- 사건과 참전 기체, 세력 정보 연결
- 키워드 검색 및 시대별 필터
- 모바일 화면 대응

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` / `/(root)` 선택.

## 데이터 원칙
작품 본편, 극장판, OVA, 소설, 만화, 게임 등 매체별 설정이 일치하지 않을 수 있습니다. 연표의 날짜와 기체 설정은 공식 자료를 기준으로 재검증하고, 정사/외전/매체별 차이를 구분해 확장합니다. 현재 데이터는 초기 큐레이션이며 완전한 공식 연표를 의미하지 않습니다.

## 면책
본 프로젝트는 비공식 팬 제작 데이터베이스입니다. 건담 및 관련 명칭·저작권은 각 권리자에게 있습니다.

## 이번 데이터 보강 (U.C. 0083 — GP02A / GP03 계열)
- GP02A 사이살리스: OVA 공식 각 화 소개에서 핵탄두 탑재·강탈(제1화) 및 핵 바주카 발사(제3화)를 확인. 수치 제원은 검증된 공식 자료를 확보하지 못해 미기재.
- GP02A MLRS 사양: 반다이 공식 웹 취급설명서에 일반 GP02A 상품과 별도 상품명으로 등재된 사실만 기록. OVA 본편의 실전 배치 사양으로 단정하지 않음.
- GP03 덴드로비움: 건담 공식 기체 소개에 따라 스테이멘(MS 유닛)과 암드 베이스 오키스(MA형 베이스)의 복합 구성, I필드 제너레이터·대형 무장·라비안 로즈 실험 및 별 부스러기 작전 투입 기록을 보강.
- GP03S 스테이멘: 덴드로비움과 분리된 MS 유닛 항목으로 추가. 독립 운용 수치 제원은 공식 근거 미확보로 미기재.
